## 说明

- 图形应用清单通过扫描 `/Applications` 和 `~/Applications` 获取。
- Homebrew 命令行工具使用 `brew leaves` 获取，仅列出手动安装的顶层软件包。
- Homebrew Cask 使用 `brew list --cask` 获取。
- macOS 系统自带应用、系统组件和未安装在上述目录中的应用可能未列出。
- 应用可能同时通过图形应用目录和 Homebrew Cask 安装，因此两个清单存在重复属于正常情况。
- 如需重新生成清单，可执行：

```bash
find /Applications -maxdepth 1 -type d -name '*.app' -print | sort
find "$HOME/Applications" -maxdepth 1 -type d -name '*.app' -print 2>/dev/null | sort
brew leaves
brew list --cask
```
